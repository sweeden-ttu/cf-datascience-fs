# Changelog

## 0.1.0 (unreleased)

- `cfds:` file system: browse, read, write, create folders, rename, copy (server-side),
  delete.
- Sign in and sign up with Cloudfronts (OpenID Connect, authorization code + PKCE).
- Opens the shared Kaggle datasets (read-only) and your own storage as workspace folders.
- Quota in the status bar.
- `CFDS_TOKEN` for headless and Kubernetes use.
